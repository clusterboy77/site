# Site Hub

Site interativo com computador animado que segue o mouse.

## Login / Contas

- Conta padrão: **admin** / **1234**
- Você pode criar novas contas na aba **"Criar Conta"**
- As contas ficam salvas no navegador (localStorage)
- Botão **"Sair (Login)"** no menu lateral para voltar à tela de login

## Arquivos
- `index.html` – estrutura
- `siteHub.css` – estilos
- `siteHub.js` – lógica + animação do computador
